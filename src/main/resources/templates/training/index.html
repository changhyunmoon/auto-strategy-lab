🔁방식
#폴드 수
첫 학습 비율 % 학습 창 일
폴드마다 검증 블록 바로 앞 (예측 기간 + 1)봉의 학습 행을 뺍니다 (purge). 최종 테스트 구간은 쓰지 않습니다. 검증 결과는 폴드 밖 예측으로 그리고, 최종 테스트용 모델은 학습 + 검증 구간 전체로 다시 학습합니다.

✂️학습 표본 상한
행 (학습 단위마다)
학습 구간 행이 이보다 많으면 무작위로 이만큼만 씁니다. 그래디언트 부스팅 · 랜덤 포레스트는 행이 많을수록 오래 걸리고 메모리를 많이 씁니다. 집 PC 기준 10~30만 행을 권합니다.
🎲난수 시드
같은 시드면 표본 선택 · 트리 무작위가 같아 결과를 다시 만들 수 있습니다.
🔀순열 중요도
「이 열이 없으면 점수가 얼마나 떨어지나」를 봅니다. 열 수 × 3번 예측하므로 시간이 더 걸립니다.
🏷️실험 이름
모델을 여러 개 고르면 「이름 · 모델」로 나뉘어 저장됩니다.
📝메모
🔒
학습이 끝나면 검증 구간으로만 평가합니다. 최종 테스트는 비교를 마치고 후보를 고른 뒤 실험 상세 화면에서 따로 실행하며, 실행할 때마다 횟수와 시각이 기록됩니다. 결측은 학습 표본의 평균으로 채우고, 표준화 기준도 학습 표본으로만 계산합니다.
