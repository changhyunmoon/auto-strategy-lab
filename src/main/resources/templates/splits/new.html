2. 날짜 정하기 UTC 날짜 · 종료일 하루 전체 포함

세 구간은 학습 → 검증 → 최종 테스트 순서로 겹치지 않아야 합니다. 구간 사이를 비워 두면 그 날짜의 행은 어느 구간에도 들어가지 않습니다. 고정 비율(70/15/15)이나 마지막 N개월 자동 분할은 쓰지 않고 날짜를 직접 고릅니다.

내부에서는 [시작일 00:00, 종료일 다음 날 00:00) UTC 로 저장합니다. 실제 적용된 경계는 아래 미리보기에 나옵니다.

사용 기간 비우면 원본 전체. 사용 시작 전 데이터는 지표 워밍업에만 쓰였습니다. 학습 모델 · 전처리 기준을 만드는 기간 검증 설정을 비교 · 선택하는 기간 (학습 뒤) 최종 테스트 선택을 끝낸 뒤 한 번 평가하는 기간 (검증 뒤) 경계 여유 분 0 이면 label_end_time 검사만 합니다.
